Local only, never committed.

STUDENT_SHUF is CORRECTED: the teacher's trees with the RELATION LABELS permuted within each sentence (seeded), the tree structure kept valid (a permuted head pointer can make a cycle, which the trainer cannot take); so T3 asks whether the student learns from the teacher's LABELS. T3 is read accordingly: STUDENT_SHUF not worse than POOL by 0.5 on both sets means the labels did not matter.
