Her finding, one run, one tagger, exploratory: a unigram code length alone does not favour the clitic splits (n't -9503 bits, 'm -3874, 're -1001, 'll -823, 've -632; only 's +1980 and 'd +202), the known weakness of description-length segmentation (a frequent whole word is cheap to code whole), while the tagger's own confidence change, split minus glued against a random-cut null from the same text, does recover them (n't +4.52, 's +1.86; every null draw below). The owner's own words point the same way: priors and COMPETENCY: how we know how to slice is how much a slice makes what we encountered less surprising to what we can already do. So the colony gets a second score.

## 1. The second score (ARM ANT_CONF)
CONFIDENCE of a program = on a fixed seeded sample of the learning stream's sentences (CAP = 300; an ARBITRARY CONSTANT, labelled), over those sentences the program changes (at least one move fires), the mean over sentences of [mean tagger margin of the sentence with the program applied minus the same without it]. The tagger is khora's own `tagWithMargins` on the pooled English parser's tagger (the one trained today, hash in the freeze file); a margin is the top class score minus the runner-up (finite margins only). The NULL of a program is the same score for a RANDOM program of the same shape: the same number of cuts at the same suffix lengths, each applied to one random token of each sentence (as in Penelope's measure). The program's rank against its null and the search-aware CEILING (the largest null confidence any tried program reaches, as structure-swarm.js) are reported; a program is FOUND on confidence only if it exceeds that ceiling. A trail is laid when the program's confidence exceeds its own null's. ANT_CONF uses trails, scouts and the guard exactly as ANT; only the score differs. Its twin is RAND_CONF (uniform random programs, same budget, guard on).

## 2. Added measures and falsifiers
Every best program of every arm is scored BOTH ways (code-length bits and confidence), so each arm is seen by both eyes. New falsifiers: A6: ANT_CONF's median best confidence does not exceed RAND_CONF's (trails add nothing on the competency score). A7: none of the six clitic forms in force on the log (`'s n't 'm 'll 've 're`) appears among the moves of any ANT_CONF run's FOUND programs while at least one morphological cut (a move that is not an apostrophe or n't form) does (the competency score also rediscovers morphology and misses the clitics). A8: the KNOWN reference program (those six cuts) scores no higher on confidence than the median ANT_CONF best (the search finds something better on the competency eye than what the treebank-learned rules give). Reported, no gate: the overlap between the two eyes' best programs.
