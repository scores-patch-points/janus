# NOTICE — generated POS priors and parameter sets (added 2026-10-14)

`priors/pos-<iso3>.json` (`POSPrior@1`) and `priors/params-<lang>.json` (`ParameterSet@1`) were generated by
`native/scripts/build-pos-prior.mjs` from the sources named in each file's `provenance`. This notice records the licence of
each source family and what was removed before publication.

| Source family | Files | Licence | Note |
|---|---|---|---|
| Universal Dependencies treebanks (train split) | 43 `pos-*` | CC BY-SA 4.0 | each treebank's README says so; read 2026-10-14 |
| Universal Dependencies — UD_Thai-PUD | `pos-tha` | CC BY-SA 3.0 | was labelled 4.0 |
| Wiktionary extraction (kaikki.org / Wikimedia) | 34 `pos-*` | CC BY-SA 4.0 | |
| Projection from CC BY-SA 4.0 anchors | 65 `pos-*` | CC BY-SA 4.0 | |
| UniMorph | 31 `pos-*` | CC BY-SA 3.0 | UniMorph's own stated licence; **verify the per-language repository before redistributing** |
| Parameter sets | 30 `params-*` | induced from the first 6,000 characters of the language's UN Universal Declaration of Human Rights text (UN; freely reproducible) plus a declared grammatical overlay | no third-party text |

Attribution: Universal Dependencies treebanks and their annotators (https://universaldependencies.org); Wiktionary contributors via
kaikki.org; the UniMorph project (https://unimorph.github.io). CC BY-SA requires attribution and share-alike for adapted data: these
files are adaptations (word → part-of-speech counts) and are offered under the same terms.

## Removed before publication
- `pos-oci` — built from UD_Occitan-TTB, which is **CC BY-NC-SA 4.0** (the file had said CC BY-SA 4.0).
- `pos-lij` — built from UD_Ligurian-GLT, which is **C-UDA 1.0** (research-use terms), not CC BY-SA.
- `pos-tyv` — 21.8 MB; too large to publish as a git blob. Rebuild locally with the builder.
- 2,907 form keys that were e-mail addresses, URLs, or runs of nine or more digits (2,905 in `pos-bel`, 1 in `pos-isl`, 1 in
  `pos-krl`): contact details and identifiers scraped from web text are not words. Each affected file's `provenance.scrubbed` says how many.
  `scripts/scrub-priors.mjs` reproduces all of the above.

- `priors/quarantined-2026-10-11/` (5 files: cjy, gan, hak, hsn, nan) — a directory the builder's own history had quarantined; not published.

## Not changed
Files that already existed on main were left byte-for-byte as they were; they were not audited by this change.
