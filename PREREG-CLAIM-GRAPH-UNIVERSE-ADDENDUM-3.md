ADDENDUM-2 left the void's `admits` (INS) a typed gap, `kind_unread`, and named two missing pieces: the kind a filler must have, and Penelope's DEF of a bound. ## 1. The kind of a class, induced (khora kernel/entity-kind-induction.js, used as an organ, not reimplemented)
- Profile: per anchor class, the relations it takes part in, never its name. From the reader's rows: `dep:<base of the dependency label of the mention's root token>`, `gov:<lemma of the token that governs it>` (what is done to or by it), and `has:<base of the label of each dependent hanging on its tokens, outside the mention>` (what it carries). The class's own words are not features.
- Induction: khora's `induceEntityKindCandidates` over each document's classes with the organ's own parameters (no value of mine: min entity count, prevalence, kind size and the random-subset search-aware null are the organ's defaults). Only kinds the organ validates (`field.stable`, not `fallbackNomination`) are kinds; the fallback licenses nothing. A class in no stable kind is UNPLACED.
- The organ is imported from the khora checkout by the HARNESS script (kinds.mjs), pinned by sha256 in the freeze file; no file under native/ imports it (Janus's own code imports no other repo).

## 2. Admission (the void's `admits`, read per query)
For a query class q: if q is placed in kind K, the void's `admits` = K; if q is unplaced it stays the typed gap `kind_unread` and nothing is admitted or refused. For a candidate c: ADMITTED if c is in K; REFUSED if c is placed in a different stable kind (shown to be of another kind); UNKNOWN if c is unplaced (a hole, not a pass and not a refusal). Ranking by tier: admitted first, then unknown, then refused; within a tier, the base arm's order. Refusal is demotion to the tail, so a refused alias still counts if the ten slots are not filled before it; the gate's harm is measured separately (K4).

## 3. Arms, twins, falsifiers (ctxadmit.py)
- A0A = A0 (bare anchor embedding) under the admits tiers. VGA = VG (the void-gated universe of ADDENDUM-2, without bindings) under the admits tiers. Twins: A0A_SHUF and VGA_SHUF, the same tiering with the induced kind labels SHUFFLED among the placed classes of the document (kind sizes kept, the structure destroyed, seeded). Controls from ADDENDUM-2: A0, VG, T_VG, ADJF, PROX.
- Falsifiers (thresholds as the parent: document-bootstrap interval above 0 and at least 0.05 recall@10, on DISJOINT): K1 A0A does not beat A0 (admits adds nothing over the label). K2 A0A does not beat A0A_SHUF (the induced kinds add nothing over random kinds). K3 VGA does not beat VG. K4 of the gold pairs whose two classes are both placed, the share that are REFUSED (placed in different kinds) is 0.2 or more (the gate would refuse true aliases). Coverage is reported and judged by no threshold: the share of classes placed in a stable kind, and the share of gold pairs whose q is placed (where the admits is unread, the gate is a typed gap and every number above is diluted by it).
- A pass needs K1 to K3 NOT hit and K4 NOT hit.

## 4. Disclosure and limits
ADDENDUM-2's DEV debugging run was seen (the void-gated universe is almost always the class's own sentences; the bare label is the strongest arm).
